# The Movies Dataset Project

## Structure

- `data/raw/`: Raw CSV files from MovieLens/Kaggle.
- `notebooks/`: Jupyter notebooks for data cleaning and analysis.
- `src/`: Python scripts for reusable code.
- `outputs/`: Generated figures and processed data.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Place raw data CSVs in `data/raw/`.

## Usage

- Run the notebook in `notebooks/` for step-by-step analysis.
- Use scripts in `src/` for batch processing or automation.

## Notes

- All paths are relative to the project root.
- Figures and processed data are saved in `outputs/`.
